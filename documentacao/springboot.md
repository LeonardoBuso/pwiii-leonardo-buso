# 🚀 Criando um Projeto Spring Boot

Acesse o site oficial para inicialização do projeto:
👉 **https://start.spring.io/**

---

## 📋 Passo a Passo de Configuração

1. **Project:** Selecione o tipo (*Gradle Kotlin*, *Gradle Groovy* ou *Maven*)
2. **Language:** Selecione a linguagem (*Java*, *Kotlin* ou *Groovy*)
3. **Spring Boot:** Escolha a versão do framework
4. **Metadata:** Configure as informações do seu projeto
5. **Packaging:** Selecione o tipo do pacote (*Jar* ou *War*)
6. **Configuration:** Selecione o formato do arquivo de configuração (*properties* ou *YAML*)
7. **Java:** Selecione a versão do Java
8. **Dependencies:** Adicione as dependências desejadas

---

## 🛠️ Configurações Deste Projeto

Neste projeto específico, utilizaremos as seguintes definições:

* **Project:** Maven
* **Language:** Java
* **Versão do Framework:** 4.1.0
* **Packaging:** Jar
* **Configuração:** Properties
* **Versão do Java:** Java 21
* **Dependências:** 
  - Spring Web
  - Lombok
  - Spring Boot Dev Tools

---

## 🎯 Finalização

1. **Gere o projeto .jar**
